What is programming?
Programming is the process of writing instructions that tell a computer what to do.
A computer cannot understand human language directly.
It understands only machine language (0s and 1s).
Programming languages (like Python, Java, C) act as a bridge between humans and computers.
A collection of instructions written to perform a task is called a program
what is a programming langauage?
A Programming Language is a language used to communicate with a computer and create software or applications.
Types of programming languages?
A Programming Paradigm is a style or way of writing programs.
The two main paradigms are:
Procedural Programming (POP)
Object-Oriented Programming (OOP)
what is python?
Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum. It was first released in 1991.
why is python a general purpose programming langauage?
A general-purpose language can be used to build many types of applications.
